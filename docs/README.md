# Documentacao do Merlin Public

Use esta pasta como fonte para contratos e decisoes do site publico.

1. `PLANOS_CONTRATO.md` — planos, pagamentos e regras Premium.
2. `PUBLIC_SIGNUP_RULES.md` — fluxo de cadastro e pagamento publico.
3. `MEU_ACESSO_VISUAL_SCOPE.md` — escopo visual da area Meu acesso.
4. `MEU_ACESSO_PLAN_CHANGE_MATRIX.md` — matriz de estados da troca de plano.

Nunca incluir credenciais, dados de clientes, chaves de licenca, respostas de pagamento reais ou identificadores privados de infraestrutura.
